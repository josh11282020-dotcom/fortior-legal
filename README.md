## Características del portal

- Responsive para móvil, horizontal y escritorio.
- Tema claro/oscuro sin cookies.
- Sin analítica, trackers, frameworks ni fuentes externas.
- Navegación accesible, enlace para saltar al contenido, foco visible y reducción de movimiento.
- Metadatos SEO, Open Graph, datos estructurados, `robots.txt`, `sitemap.xml` y página 404.
- Matriz de datos basada en el comportamiento real de la app.
- Flujo externo de eliminación mediante correo prellenado.

## Desarrollo local

No requiere instalación ni compilación. Abre `index.html` o sirve la carpeta con cualquier servidor HTTP estático.

Antes de modificar información legal o funcional:

1. comprobar el comportamiento del binario actual;
2. actualizar política, formulario Data safety y textos dentro de la app de forma consistente;
3. validar todos los enlaces;
4. revisar el diff para evitar datos personales, credenciales o promesas no verificables.

Consulta [`PLAY_STORE_CHECKLIST.md`](PLAY_STORE_CHECKLIST.md) antes de presentar una versión a Google Play.
